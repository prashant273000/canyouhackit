# Project Overview

## Purpose

Define the project goal, scope, and current state for the hackathon team.

## Current Goal

Build AI Feed Shield: a Chrome browser extension that acts as a reader-controlled safety
layer between web content and the person viewing it.

## Current Status

- The repository, CYHI logging, and documentation folder are in place.
- A Phase 1 Chrome Manifest V3 extension skeleton exists in `feature/extension/`.
- No AI, ML, backend, parser, or moderation functionality has been implemented.
